## Hi there 👋
# Preksha Health Point 🩺

Official website for **Preksha Health Point** — a retail store for home healthcare and medical monitoring equipment, including digital thermometers, glucometers, digital BP monitors, pulse oximeters, SpO2 monitors, and ECG machines.

Live site: `https://prekshahealthpoint.com` *(update once your domain is live)*

---

## 📖 About

Preksha Health Point helps customers find genuine, doctor-recommended medical devices for home use — with guidance on choosing the right device and support after purchase. This repository contains the source code for the store's website, hosted via **GitHub Pages**.

---

## ✨ Features

- Responsive, mobile-friendly design
- Home, About, Products, Testimonials, and Contact pages
- Product category showcase (thermometers, glucometers, BP monitors, pulse oximeters, SpO2 monitors, ECG machines)
- Contact section with shop location, phone, and email
- Fast-loading static site — no server or database required

## 🚀 Getting Started (Local Preview)

No build tools or dependencies are required — it's a static site.

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Preksha_Health_Point.git
   ```
2. Open the project folder and double-click `index.html`, or serve it locally:
   ```bash
   cd Preksha_Health_Point
   python3 -m http.server 8000
   ```
3. Visit `http://localhost:8000` in your browser.

---

## 🌐 Deployment

This site is deployed using **GitHub Pages**:

1. Go to the repository **Settings → Pages**
2. Under **Build and deployment**, set Source to `Deploy from a branch`, branch `main`, folder `/ (root)`
3. (Optional) Add a custom domain under **Custom domain** and configure the matching DNS records with your registrar
4. Enable **Enforce HTTPS** once the domain check passes
